보호 구문을 활용하라

2025년 10월 12일

[전체][에세이]

추석 때 켄트 벡의 『Tidy First?』를 읽게 되었다. 이 책에서 첫 번째로 나오는 개념인 '보호 구문'을 설명해 보도록 하겠다.

보호 구문이란, 전제조건이라고 생각하면 된다. 즉, 어떤 $x$ 로직이 돌아가기 위해서 선재적으로 만족되어야 하는 조건들을 직관적으로 명시할 수 있는 방법이다.

예제가 최고의 문서이므로, 나의 github.com/chebread/cvtr 레거시 코드를 통해 설명해 보도록 하겠다.

if len(os.Args) >= 2 {
		switch os.Args[1] {
		case "convert":
			if len(os.Args) <= 5 {
				fmt.Printf("error: Not enough arguments provided\n")
			} else {
				amountStr := os.Args[2]
				sourceCurrency := os.Args[3]
				keyword := os.Args[4]
				targetCurrency := os.Args[5]

				if keyword != "to" {
					fmt.Printf("Error: Use 'to' keyword, instead of '%s' keyword\n", keyword)
					return
				}
                ... 코드 생략 ...

먼저 보호 구문으로 바꾸기 위해서는 전제조건을 찾아야 한다.

위 코드에서 전제조건으로 사용되는 코드는

  • if len(os.Args) >= 2 { ... }
  • if len(os.Args) <= 5 { ... }
  • if keyword != "to" { ... }

이다.

참고로 이게 왜 전제조건이냐 하면, 이 3가지가 만족되지 않으면 로직 실행 전에 프로그램을 종료해버리기 때문이다. 즉, 이것은 로직 실행의 선재적인 조건에 해당된다.

전제조건을 찾았으면 이제 보호 구문으로 바꾸면 된다.

보호 구문은 무조건 단일 if 문을 사용하며, 로직 실행 부의 최상단에 위치한다. 최상단에 위치해야 하는 까닭은, 최상단에 위치해야만 그 로직 전체에 '전제 조건'으로 비춰질 수 있기 때문이다.

먼저 if len(os.Args) >= 2 { ... } 부터 바꿔보도록 하겠다.

if len(os.Args) < 2 {
	help()
	return
}

switch os.Args[1] {
	... 코드 ...
}

이렇게 if len(os.Args) >= 2 { ... }를 전제조건처럼 단독 if문으로 최상단에 위치하고, switch 문을 if else 문 바깥으로 빼면 된다.

이제 if len(os.Args) <= 5 { ... }를 바꿔 보겠다.

if len(os.Args) < 2 {
	help()
	return
}

switch os.Args[1] {
	if len(os.Args) <= 5 {
		boldRed("error: Not enough arguments provided\n")
		break
	}

    ... 코드 ...
}

이것도 if else 문에서 빠져나와서 if len(os.Args) <= 5 { ... }를 전제조건화하면 된다.

이제 if keyword != "to" { 를 바꿔보자.

if len(os.Args) < 2 {
	help()
	return
}

switch os.Args[1] {
	if len(os.Args) <= 5 {
		boldRed("error: Not enough arguments provided\n")
		break
	}

	if keyword := os.Args[4]; keyword != "to" {
		boldRed("error: Use 'to' keyword, instead of '%s' keyword\n", keyword)
		break
	}

	... 코드 ...
}

keyword 변수는 이 전제조건에서만 쓰임으로 이렇게 처리했다.

이게 레거시 코드이고

if len(os.Args) >= 2 {
		switch os.Args[1] {
		case "convert":
			if len(os.Args) <= 5 {
				fmt.Printf("error: Not enough arguments provided\n")
			} else {
				amountStr := os.Args[2]
				sourceCurrency := os.Args[3]
				keyword := os.Args[4]
				targetCurrency := os.Args[5]

				if keyword != "to" {
					fmt.Printf("Error: Use 'to' keyword, instead of '%s' keyword\n", keyword)
					return
				}
                ... 코드 생략 ...

이게 보호 구문으로 바꾼 코드이다.

if len(os.Args) < 2 {
	help()
	return
}

switch os.Args[1] {
	if len(os.Args) <= 5 {
		boldRed("error: Not enough arguments provided\n")
		break
	}

	if keyword := os.Args[4]; keyword != "to" {
		boldRed("error: Use 'to' keyword, instead of '%s' keyword\n", keyword)
		break
	}

	amountStr := os.Args[2]
	sourceCurrency := os.Args[3]
	targetCurrency := os.Args[5]
}

보호 구문을 활용한 코드가 더 읽기 쉬울 것이다.

이제부터 이렇게 전제 조건으로 if문을 사용하는 경우에는 보호 구문을 적극 활용 해보기 바란다.
