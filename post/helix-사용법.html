소개 (INTRODUCTION)

Helix 에디터에 오신 것을 환영합니다! Helix는 모달(modal) 방식이라는 점에서 여러분이 익숙한 다른 에디터들과 다릅니다. 즉, 텍스트 편집을 위한 여러 가지 모드를 가지고 있습니다. 주로 사용하게 될 모드는 일반(Normal) 모드와 입력(Insert) 모드입니다. 일반 모드에서는 키를 눌러도 실제로 텍스트가 입력되지 않습니다. 대신, 텍스트에 대한 다양한 작업을 수행하게 됩니다. 이를 통해 더 효율적인 편집이 가능합니다. 이 튜토리얼은 Helix의 모달 편집 기능을 활용하는 방법을 알려드릴 것입니다. 시작하려면 CapsLock 키가 눌려 있지 않은지 확인하고, 첫 번째 레슨에 도달할 때까지 j 키를 길게 누르세요.

Normal 모드가 에디터의 중심 기반(기본 상태)이며, Insert 모드나 Select 모드 등은 특정 작업을 수행한 뒤 다시 일반 모드로 돌아오게 되는 보조적인 모드이다. 즉, Insert 모드에서 Select 모드를 가려고 해도 일단 Normal 모드를 거쳐야 한다. Normal 모드에서 Insert 모드든, Select 모드든 Normal이 아닌 모드로 어유일하게 들어 갈 수 있기 때문이다.

Insert 모드나 Select 모드 등에서 Escape를 누르면 언제나 Normal 모드로 들어간다.

참고로, Helix의 모드는 다음과 같다.

  • 일반(Normal) 모드: 에디터를 켤 때의 기본 모드입니다. 텍스트 이동, 선택, 편집 명령을 내립니다.
  • 입력(Insert) 모드: i, a, o 등을 눌러 진입하며, 텍스트를 직접 입력합니다.
  • 선택(Select) 모드: 일반 모드에서 v를 눌러 진입합니다. 이 모드에서는 커서를 이동할 때마다 선택 영역이 계속 확장됩니다. (Vim의 Visual 모드와 유사합니다.)
  • 명령(Command) 모드: 일반 모드에서 :를 눌러 진입합니다. 파일 저장(:w), 종료(:q) 등 에디터 자체를 제어하는 명령을 입력합니다.
  • 매치(Match) 모드: 일반 모드에서 m을 눌러 진입합니다. 괄호 쌍 감싸기, 괄호 내부 선택 등의 작업을 수행합니다.

1.1 기본 커서 이동 (BASIC CURSOR MOVEMENT)

         ↑
         k        * h는 왼쪽에 있습니다.
     ← h   l →    * l은 오른쪽에 있습니다.
         j        * j는 아래 화살표처럼 생겼습니다.
         ↓

커서는 위에서 볼 수 있듯이 h, j, k, l 키를 사용하여 이동할 수 있습니다. 커서(방향) 키도 작동하지만, 앞으로 사용할 다른 키들과 가깝게 위치한 hjkl 키를 사용하는 것이 훨씬 빠릅니다. 이리저리 이동하며 hjkl에 익숙해져 보세요. 준비가 되면 j를 길게 눌러 다음 레슨으로 넘어가세요.

메모장이나 워드에서는 커서가 글자 사이에서 깜빡이는 '선(|)' 형태이지만, Helix에서는 글자 하나를 통째로 감싸는 '네모난 블록' 형태이다. Helix에서 이 커서 블록은 "현재 이 글자 1개가 선택되어 있다"는 것을 의미한다. 즉, 커서란 최소 1글자 크기를 가진 선택 영역이다. 단, Insert 모드에서 커서는 선 형태로 제공된다. 커서는 모든 모드에 항상 존재한다. 커서를 이동 시킬 수 있는 방법 중 하나는 hjkl이다.

커서 이동은 Insert 모드에서 방향키로도 할 수 있으나, 이제부터는 Normal 모드에서 hjkl로 해야 한다.

  • h는 왼쪽에 있으니 왼쪽(좌)으로 이동을 의미한다.
  • l는 오른쪽에 있으니 오른쪽(우)으로 이동을 의미한다.
  • j는 아래 화살표 처럼 생겼으니, 아래(하)로의 이동을 의미한다.
  • k는 위(상)로의 이동을 의미한다.

1.2 Helix 종료하기 (EXITING HELIX)

  1. : 를 입력하여 명령(Command) 모드로 들어갑니다. 커서가 화면 맨 아래로 이동할 것입니다.

  2. q 또는 quit를 입력하고 Enter를 눌러 Helix를 종료합니다.

참고: 저장되지 않은 변경 사항이 있으면 quit 명령이 실패합니다. 이러한 변경 사항을 무시하고 강제 종료하려면 q! 또는 quit!를 입력하세요. 파일을 저장하는 방법은 나중에 배울 것입니다.

명령을 입력하지 않고 명령 모드를 종료하려면 Escape를 누르세요. 이제 다음 레슨으로 넘어가세요.

Command 모드는 Normal, Select 모드에서 :를 입력하면 들어갈 수 있다.

Command 모드에서 q를 입력하고 Enter를 누르면 Helix 종료를 할 수 있으며 w 하지 않은 파일은 q 명령을 할 수 없다. w 하지 않은 파일에서 Helix를 종료하고 싶다면, q! 명령을 써야 한다.

1.3 삭제 (DELETION)

커서 아래에 있는 문자를 삭제하려면 d 키를 입력하세요.

  1. 아래 -->로 표시된 줄로 커서를 이동하세요.

  2. 여분의 문자로 커서를 이동한 후, d를 입력하여 삭제하세요.

--> Thhiss senttencee haass exxtra charracterss.
    This sentence has extra characters.

문장이 올바르게 수정되면 다음 레슨으로 넘어가세요.

Helix에서 d는 단순히 글자를 지우는 키가 아니라, "현재 선택된 영역을 삭제하라"는 명령어이다. 따라서 커서가 글자 위에 올라가 있는 상태는 '그 글자 1개가 선택된 상태'이므로, d를 누르면 그 글자가 즉시 지워진다. 글자가 지워지면 그 오른쪽에 있던 글자들이 왼쪽으로 한 칸씩 당겨져 온다. d 명령어는 오직 Normal, Select 모드에서만 사용 가능하다.

1.4 입력 모드 (INSERT MODE)

i 키를 입력하여 입력(Insert) 모드로 들어갑니다.

  1. 아래 -->로 표시된 줄로 커서를 이동하세요.

  2. 텍스트가 누락된 곳으로 이동한 후 i를 눌러 입력 모드로 들어갑니다. 이제 입력하는 키가 텍스트로 입력됩니다.

  3. 누락된 텍스트를 입력하세요.

  4. Escape를 눌러 입력 모드를 종료하고 일반 모드로 돌아갑니다.

  5. 아래 줄과 일치할 때까지 이 과정을 반복하세요.

--> Th stce misg so.
    This sentence is missing some text.

참고: 상태 표시줄에 현재 모드가 표시됩니다. i를 입력하면 'NOR'가 'INS'로 변경되는 것을 확인해 보세요.

오직 Normal, Select 모드에서 i를 누르면 Insert 모드로 들어갈 수 있다. Insert 모드에서 esc를 누르면 Normal 모드로 들어가게 된다.

1.5 파일 저장하기 (SAVING A FILE)

파일을 저장하려면 :w 또는 :write를 입력하세요.

  1. 앞서 설명한 대로 :q!를 사용하여 Helix를 종료하거나, 새 터미널을 여세요.

  2. hx FILENAME을 실행하여 Helix에서 파일을 엽니다.

  3. 파일의 내용을 약간 편집합니다.

  4. : 를 입력하여 명령 모드로 들어갑니다.

  5. w 또는 write를 입력하고 Enter를 눌러 파일을 저장합니다.

wq 또는 write-quit를 입력하여 저장과 종료를 동시에 할 수도 있습니다.

참고: 원하는 경로에 저장하기 위해 w / write 명령 뒤에 선택적으로 파일 경로를 입력할 수 있습니다. 참고: 파일에 저장되지 않은 변경 사항이 있으면 상태 표시줄의 파일 이름 옆에 플러스 [+] 기호가 나타납니다.

    • q / quit 및 q! / quit! 명령은 Helix를 종료합니다. 전자는 저장되지 않은 변경 사항이 있을 때 실패하며, 후자는 이를 무시하고 닫습니다.

2.1 추가적인 입력 명령 (MORE INSERT COMMANDS)

일반적인 입력 명령의 예는 다음과 같습니다:

  • a - 선택 영역의 뒤에 입력합니다. (a는 'append'를 의미합니다)

  • I - 줄의 시작 부분에 입력합니다.

  • A - 줄의 끝 부분에 입력합니다.

3.1 이동과 선택 (MOTIONS AND SELECTIONS)

w를 입력하면 다음 단어까지 앞쪽으로 선택합니다.

d 키는 실제로 커서에 있는 문자 하나만 삭제하는 것이 아니라, 선택된 모든 텍스트를 삭제합니다. 즉, 기본 상태의 커서는 '단일 문자가 선택된 상태'와 같습니다.

  1. 아래 -->로 표시된 줄로 커서를 이동하세요.

  2. 삭제해야 할 단어의 시작 부분으로 이동합니다.

  3. w를 입력하여 다음 단어의 시작 부분까지 선택합니다.

  4. d를 입력하여 선택 영역을 삭제합니다.

  5. 줄에 있는 모든 불필요한 단어에 대해 이 과정을 반복하세요.

--> This sentence pencil has vacuum extra words in the it.
    This sentence has extra words in it.

3.2 추가적인 이동 명령 (MORE MOTIONS)

앞서 보았듯이 w를 입력하면 다음 단어의 시작점까지 앞쪽으로 이동하며 그 사이의 텍스트를 선택합니다. 이는 텍스트 안에서 이동하거나, 특정 텍스트를 선택하여 작업할 때 유용합니다.

일반적인 이동 명령은 다음과 같습니다:

  • w - 다음 단어의 시작 지점 앞까지 이동합니다.

  • e - 현재 단어의 끝까지 앞으로 이동합니다.

  • b - 현재 단어의 시작 지점까지 뒤로 이동합니다.

커서 아래에 있는 단어를 선택하려면 e와 b를 조합해서 사용하세요.

  1. 아래 -->로 표시된 줄로 커서를 이동하세요.

  2. 'd' 글자로 이동합니다.

  3. e를 입력하여 단어의 절반을 선택합니다.

  4. b를 입력하여 나머지 절반을 선택합니다.

--> The Middle Kingdom.

3.3 단어(words)와 공백 단위 단어(WORDS) (WORDS AND words)

w, e, b 이동 명령은 각각 대문자인 W, E, B와 대응되며, 이는 일반적인 단어(words) 대신 공백 단위로 구분된 큰 단어(WORDS)를 탐색합니다. WORDS는 오직 공백(whitespace)으로만 구분되는 반면, words는 공백 외에도 다른 문자(기호 등)로 구분될 수 있습니다.

  1. 아래 -->로 표시된 줄의 맨 앞으로 커서를 이동하세요.

  2. 줄의 끝에 도달할 때까지 w를 반복해서 눌러 개별 단어들을 선택해 봅니다.

  3. one-of-a-kind를 모두 지나가려면 7번의 키 입력이 필요하다는 점에 주목하세요. "modal"은 3번의 키 입력이 필요합니다.

  4. 다시 -->로 표시된 줄의 처음으로 커서를 되돌리세요.

  5. 이번에는 W를 반복해서 눌러 WORDS 단위로 선택해 봅니다.

  6. one-of-a-kind와 "modal"이 모두 한 번의 키 입력만으로 선택되는 것을 확인하세요.

--> Helix is a one-of-a-kind "modal" text editor

3.4 변경 명령 (THE CHANGE COMMAND)

c를 입력하여 현재 선택 영역을 변경합니다.

변경(change) 명령은 현재 선택 영역을 삭제하고 바로 입력 모드로 들어가므로, di (삭제 후 삽입)의 매우 흔한 단축 방식입니다.

  1. 아래 -->로 표시된 줄로 커서를 이동하세요.

  2. 잘못된 단어의 시작 부분으로 이동한 후 e를 입력하여 단어를 선택하세요.

  3. c를 입력하여 단어를 삭제함과 동시에 입력 모드로 들어갑니다.

  4. 올바른 단어를 입력하세요.

  5. 아래 줄과 완전히 같아질 때까지 반복하세요.

--> This paper has heavy words behind it.
    This sentence has incorrect words in it.

3.5 이동 명령과 횟수 지정 (COUNTS WITH MOTIONS)

이동 명령 앞에 숫자를 입력하면 해당 동작을 그 횟수만큼 반복합니다.

  1. 아래 -->로 표시된 줄로 커서를 이동하세요.

  2. 2w를 입력하여 앞으로 2단어 이동합니다.

  3. 3e를 입력하여 3번째 단어의 끝부분으로 이동합니다.

  4. 2b를 입력하여 뒤로 2단어 이동합니다.

  5. 다른 숫자들로 위의 과정들을 연습해 보세요.

--> This is just a line with words you can move around in.

3.6 선택 / 확장 모드 (SELECT / EXTEND MODE)

  1. 아래 -->로 표시된 줄로 커서를 이동하세요.

--> 줄로 이동하여, 일반 모드 상태로 괄호 사이의 아무 위치(예: 'x' 위치)에 커서를 놓고 mi( 또는 mi) 를 누르면 괄호 내부의 전체 내용물만 선택됩니다 (괄호 자체는 제외됨). 선택이 끝나면 평소처럼 원하는 작업(예: c를 눌러 변경)을 수행할 수 있습니다.

--> outside and (inside x parentheses) - and outside again

아래 문장들을 통해 [] 나 {}, 또는 이들이 중첩된 조합에서도 똑같이 작동하는지 테스트해 보세요 (항상 커서를 바로 감싸고 있는 가장 가까운 괄호 쌍을 기준으로 작동합니다). "" 같은 기호에서도 동작합니다.

--> test [ with square brackets ] !
--> try ( with nested [ pairs of ( parentheses) and "brackets" ])

12.3 매치 모드 주변 선택 사용하기 (USING MATCH MODE SELECT AROUND)

내부 내용물뿐만 아니라 괄호(구분자) 자체까지 포함하여 "주변(around)"을 모두 선택하고 싶다면 ma 선택 명령을 사용합니다. 예를 들어 아래 줄로 이동하여 () 사이 아무 곳에 커서를 두고 ma( 또는 ma) 를 누르면, 둘러싼 () 까지 포함하여 내용 전체가 선택됩니다. 평소처럼 선택 영역에 대고 원하는 작업을 할 수 있으며, 예를 들어 ma(d를 누르면 통째로 삭제됩니다.

--> you ( select x around ) to include delimiters in the select

이 명령어 역시 당연히 다른 종류의 괄호나 구분자에서도 동작합니다:

--> try [ with 'square' brackets ] too!

12.4 매치 모드 감싸기 사용하기 (USING MATCH MODE SURROUND)

매치 모드를 사용하여 현재 선택 영역의 양옆에 괄호 등의 쌍을 씌울 수도 있습니다(surround). 예를 들어 아래 줄로 이동한 후:

  • i) "select all of this" 부분을 선택합니다 (예: 일반 모드에서 select 단어 앞으로 이동 후, v를 눌러 선택 모드로 진입하고 4e를 눌러 다음 4단어를 선택).

  • ii) ms( 또는 ms) 를 눌러 선택 영역 양 끝에 괄호를 씌워 보세요.

--> so, select all of this, and surround it with ()

다른 구분자로도 똑같이 할 수 있습니다: 예를 들어 아래의 WORD 위에서 ms'를 누르면 양옆에 '' (작은따옴표)가 씌워집니다. ""나 {}, []를 추가하는 것도 시도해 보세요.

--> surround this WORD !

12.5 매치 모드 감싸기 삭제 사용하기 (USING MATCH MODE DELETE SURROUND)

md 명령을 사용하여 텍스트를 감싸고 있는 괄호 쌍을 삭제할 수 있습니다. 아래 줄에서 () 쌍 내부 아무 곳으로 커서를 이동하세요 (예: 'x' 위). 일반 모드 상태에서 md( 또는 md) 를 누르면 감싸고 있던 괄호 쌍이 지워집니다.

--> delete (the x pair of parentheses) from within!

자연스럽게 다른 종류의 둘러싼 기호들도 지울 수 있습니다:

--> delete (nested [delimiters]): "this" will delete the nearest
matching surrounding pair.
--> delete "layers "of" quote marks" too: this will delete the
nearest previous and following quote marks

존재하지 않는 구분자 쌍을 삭제하려고 하면 하단 상태 바에 오류가 표시되며 아무 일도 일어나지 않습니다.

12.6 매치 모드 감싸기 교체 사용하기 (USING MATCH MODE REPLACE SURROUND)

mr 명령을 사용하여 텍스트를 감싸고 있는 기호 쌍을 다른 기호 쌍으로 교체할 수 있습니다. 아래 줄에서 () 쌍 내부 아무 곳으로 이동한 후 (예: 'x' 위치), 일반 모드에서 mr([ 를 누르면 () 쌍이 [] 쌍으로 바뀝니다.

--> replace the (pair from x within), with something else

이 명령은 커서를 감싸는 가장 가까운 쌍에 작용하므로, 다음 문장들에서 여러 가지 교체 연습을 해보세요:

--> some (nested surroundings [can be replaced])
--> this "works with 'other surroundings' too"

존재하지 않는 쌍을 교체하려고 시도해 보세요: 하단 바에 오류 경고가 표시되고 아무 동작도 하지 않습니다.

m 키를 눌러 매치 모드로 들어갈 수 있습니다. 팝업에서 사용 가능한 동작들이 표시됩니다. 이 모드를 통해 다음 작업들을 할 수 있습니다:

  • mm을 입력하여 짝을 이루는 기호(괄호 등) 반대편으로 점프합니다 (커서가 기호 위에 있어야 합니다).

  • mi( 와 같은 명령으로 커서를 둘러싼 괄호 내부만 선택합니다 (기호 자체는 제외).

  • ma( 와 같은 명령으로 커서를 둘러싼 괄호 쌍과 내부를 모두 선택합니다.

  • md( 와 같은 명령으로 둘러싸고 있는 괄호 쌍을 삭제합니다.

  • ms( 를 사용하여 현재 선택 영역 양옆을 괄호 기호로 감쌉니다.

13.1 새 분할 창 만들기 (CREATE NEW SPLIT)

일반 모드에서 Ctrl-w를 누르면 창(Window) 메뉴가 열리고 사용 가능한 명령어 목록이 표시됩니다.

현재 창의 오른쪽 절반에 수직 분할(vertical split)로 새로운 빈 버퍼를 열려면 Ctrl-w nv를 사용하세요 (즉, Ctrl과 w를 동시에 누른 다음, 손을 떼고 n, v를 차례로 누릅니다). 현재 창이 수직으로 두 개로 분할될 것입니다. 새로운 빈 버퍼가 오른쪽 절반에 나타나며 커서가 그곳으로 자동 이동합니다.

수평 분할(horizontal split)로 새로운 빈 버퍼를 만들려면 Ctrl-w ns를 누르세요. 이 작업은 현재 창을 수평으로 둘로 나누고 새 버퍼를 만들며 커서를 새로운 수평 창으로 이동시킵니다.

13.2 분할 창 간 이동하기 (MOVE BETWEEN SPLITS)

Ctrl-w k를 사용하면 현재 창 위에 있는 분할 창으로 이동합니다. Ctrl-w j를 누르면 아래쪽 분할 창으로 이동합니다. Ctrl-w h는 왼쪽 창으로, Ctrl-w l은 오른쪽 창으로 이동시킵니다. 분할 창이 열린 순서대로 다음 창으로 계속 넘어가려면 Ctrl-w w를 누르세요.

이제 새로운 버퍼와 분할 창에서 원하는 작업을 할 수 있습니다. 해당 버퍼 창을 다 쓰고 나면 Ctrl-w q를 눌러 창을 닫을 수 있습니다. Ctrl-w l을 누른 후 Ctrl-w j를 눌러 우측 하단의 창으로 이동한 다음, Ctrl-w q를 눌러 해당 분할 창만 닫아 보세요.

현재 활성화된 창을 제외한 모든 분할 창을 한 번에 닫으려면 Ctrl-w o를 누르면 됩니다. Ctrl-w nv로 세 번째 수직 창을 열고, Ctrl-w h를 두 번 눌러 맨 왼쪽 창으로 이동한 다음, 이 상태에서 Ctrl-w o를 눌러 이 창을 제외한 나머지 창을 전부 닫아 보세요.

13.3 현재 버퍼 분할하기 (SPLIT CURRENT BUFFER)

Ctrl-w s를 사용하여 현재 보고 있는 버퍼를 그대로 수평 분할하고, Ctrl-w v를 사용하여 수직으로 분할합니다. 동일한 버퍼 내용이 양쪽 분할 창에 모두 표시될 것입니다.

다시 단일 창 보기로 돌아가려면 Ctrl-w o를 눌러 여분의 분할 창들을 닫으세요.

13.4 명령어를 사용하여 분할하기 (USE COMMANDS TO SPLIT)

명령 모드인 :vsplit (짧게 :vs) 및 :hsplit (짧게 :hs) 명령을 사용하여 특정 버퍼를 수직 또는 수평으로 분할할 수도 있습니다. 예를 들어 다음 명령을 입력해 보세요:

:vs something

오른쪽에 "something"이라는 이름의 새 수직 창이 열립니다. 여기서 "something"은 기존에 존재하는 파일이 아니므로 해당 이름을 가진 새 버퍼가 열립니다; 하지만 "something" 대신 실제 파일 이름을 입력하면 새 창에 해당 파일이 열리게 됩니다. 마찬가지로 다음 명령을 입력할 수 있습니다:

:hs some_more

아래쪽 창에 "some_more"라는 이름의 새 버퍼가 열립니다. "some_more" 자리에 열고 싶은 파일이나 경로를 넣으면 빈 버퍼 대신 특정 파일을 바로 열 수 있습니다.

13.5 분할 창 교환하기 (SWAPPING SPLITS)

:vs hello1 명령으로 왼쪽에 분할 창을 열고, :hs hello2 명령으로 아래쪽에 창을 하나 더 여세요.

hello2 창에 있는 상태에서 Ctrl-w K를 누르면 위쪽에 있는 창과 위치를 교환합니다. 이제 hello2가 맨 위로 올라가고 hello1이 아래로 내려갑니다.

여전히 hello2에 있는 상태에서 이번엔 Ctrl-w H를 누르면 왼쪽 창과 위치를 바꿉니다: 이제 hello2가 왼쪽에, 튜토리얼 창이 우측 상단에 배치됩니다. Ctrl-w 뒤에 대문자 HJKL을 사용하면 각각 왼쪽 / 아래쪽 / 위쪽 / 오른쪽의 버퍼 창과 자리를 바꿀 수 있습니다.

다시 튜토리얼 창으로 돌아온 뒤, Ctrl-w o를 눌러 이 창 하나만 남겨 두세요.

13.6 분할 창 위치 바꾸기 (TRANSPOSE SPLITS)

:vs hello1을 입력하여 수직 창을 열고, :hs hello2를 입력해 수평 창을 하나 여세요.

튜토리얼 창으로 커서를 옮긴 뒤 Ctrl-w t를 눌러 이 창에서 파생된 분할 구도를 위치 반전(transpose) 시킵니다: 이제 hello1과 hello2가 튜토리얼 창의 우측이 아닌 '아래쪽'에 배치될 것입니다. Ctrl-w t를 한 번 더 누르면 원래 구도로 되돌아갑니다.

hello1 창으로 이동한 뒤 Ctrl-w t를 누르면 이번엔 여기서 열렸던 수평 분할 구조가 반전됩니다: 이제 hello2가 hello1의 '아래쪽'이 아닌 '오른쪽'에 위치합니다. Ctrl-w t를 눌러 원래 상태로 돌려놓으세요.

다시 튜토리얼 창으로 돌아와 Ctrl-w o를 눌러 튜토리얼 창을 제외한 모든 창을 닫으세요.

13.7 파일 피커에서 분할 창 열기 (OPEN SPLIT FROM FILEPICKER)

파일 피커(file picker) 화면에서 직접 분할 창으로 파일을 열 수도 있습니다. space f를 눌러 파일 피커를 엽니다. 거기서 텍스트를 입력해 퍼지 매칭(fuzzy matching) 검색을 할 수 있고, 위아래 화살표를 사용해 선택한 파일(> 기호로 표시됨)을 변경할 수 있습니다. 파일 피커를 종료하려면 Escape를 누르세요.

파일 피커에서 원하는 파일을 아무거나 선택하세요. 여기서 Enter를 누르면 현재 보고 있는 창에 그 파일이 열리게 됩니다 (지금은 누르지 마세요). 하지만 새 분할 창으로 해당 파일을 열 수도 있습니다. Ctrl-v를 누르면 선택한 파일이 새로운 수직 분할 창으로 열립니다. 다시 space f를 누르고 파일을 고른 뒤, 이번엔 Ctrl-s를 눌러 수평 분할 창으로 열어 보세요.

튜토리얼 창으로 다시 돌아와서 Ctrl-w o를 눌러 이 창을 뺀 나머지 창을 모두 닫으세요.

분할 창(Splits)을 사용하면 같은 버퍼를 여러 개의 창에 동시에 띄우거나, 서로 다른 여러 버퍼를 볼 수 있습니다. 메인 창 및 분할 관련 명령어에 접근하려면 Ctrl-w를 누르세요. Ctrl-w hjkl을 통해 분할 창 사이를 이동할 수 있고, Ctrl-w q로 창을 닫을 수 있으며, Ctrl-w o를 사용해 현재 보고 있는 창만 남기고 전부 닫을 수 있습니다.

또한 :vs FILENAME 과 :hs FILENAME 명령어를 사용해서 창을 분할하며 열 수도 있습니다.
